# My Websites Dashboard

A clean, responsive **Websites Dashboard** built using pure HTML, CSS, and JavaScript. This platform serves as a central hub to showcase various web pages.

## 🚀 Features

* **Project Showcases:** Interactive cards linking directly to standalone web projects (Demo 1, Demo 2, etc.).
* **Search Functionality:** Built-in search bar to quickly filter through listed websites.
* **Theme Toggle:** Integrated dark/light mode toggle for a personalized user experience.
* **Fully Responsive:** Optimized layout that adapts seamlessly across mobile, tablet, and desktop devices.

## 🛠️ Technologies Used

* **HTML5:** Semantic structure for the dashboard and layout elements.
* **CSS3:** Custom layouts, responsiveness, and dark mode transitions.
* **JavaScript (ES6):** Dynamic search handling and theme switching functionalities.
